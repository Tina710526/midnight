# 午夜 11:11｜鬼屋解謎

一款精緻暗黑風格的點擊式密室逃脫遊戲。探索廢棄洋樓、蒐集道具與線索、破解密碼，揭開失蹤少女的秘密。

## 如何遊玩
1. 下載或複製本專案。
2. 直接以瀏覽器開啟 `index.html`。
3. 點擊場景中的物件探索，閱讀線索並收集道具。
4. 使用提示按鈕取得方向，解開謎題並逃出洋樓。

## 主要功能
- 四個探索區域
- 點擊式物件互動
- 道具背包與線索紀錄
- 密碼鎖與文字謎題
- 驚嚇事件、生命值與多種結局
- 可重新開始遊玩

## GitHub Pages 部署
1. 建立 GitHub repository，例如 `midnight-1111`。
2. 將 `index.html`、`AGENTS.md`、`README.md` 上傳至 repository 根目錄。
3. 進入 **Settings → Pages**。
4. 在 **Build and deployment** 選擇 **Deploy from a branch**。
5. Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
6. 等待 GitHub Pages 部署完成，使用頁面提供的網址瀏覽。

## AI 協作
修改或擴充本專案前，請先閱讀根目錄的 `AGENTS.md`，並遵守其中的遊戲流程、視覺風格、檔案命名與驗收規範。
